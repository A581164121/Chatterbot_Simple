# ChatterBot-Simple 
## 🤖 A rule-based and AI-powered chatbot built using Python and ChatterBot, to talk like a human.

### Project Info This project shows my chatbot skills by integrating ChatterBot, a machine learning conversational AI, to generate smart and context aware responses. The chatbot is trained using chatterbot_corpus datasets so it can handle user interactions.

**Features** 
- ✅ Conversational AI – Generates intelligent replies based on trained data. 
- ✅ Custom Training – Uses dataset to train chatbot. 
- ✅ Interactive Responses – Engages user with meaningful replies. 
- ✅ Rule-Based + AI Model – Combines predefined rules with machine learning. 
- ✅ Scalable & Extensible – Can be used in real applications.

**Tech Used** 
- 🔹 Python 3.11 – For scripting and logic. 
- 🔹 ChatterBot – AI chatbot library to generate responses. 
- 🔹 ChatterBot Corpus – Pretrained dataset for chatbot. 
- 🔹 NLTK & SpaCy – For NLP and text analysis. 
- 🔹 SQLite – Database to store chatbot responses and training data. 
- 🔹 Git & GitHub – For version control and collaboration.

- 🚀 Chatbot Development – Implemented ChatterBot for smarter conversations. 
- 🚀 NLP – Text processing techniques. 
- 🚀 Python – Structured code writing. 
- 🚀 Version Control (Git/GitHub) – Project management and deployment. 
- 🚀 Debugging & Troubleshooting – Error fixing and optimization.
